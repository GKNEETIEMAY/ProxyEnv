# RouteSpan v0.3.0 M5 人工验收手册

## 开工条件

维护者准备 Windows 客户端、获准管理的 Windows OpenSSH 测试机，以及隔离的非 root Linux OpenSSH 测试机。记录 RouteSpan 安装包 SHA 和签名、OS、OpenSSH、默认 Shell、Clash Verge、CC Switch、Codex、Claude Code 与 VS Code Remote 版本。为出口、模型请求和配置恢复准备专用测试账号与可丢弃的配置，确认模型请求预算。测试前备份配置，记录脱敏的文件摘要、主机信任证据和预期监听。变更主机密钥、账号或服务端策略前结束旧会话。

### Windows 生产准入

- **G1 主机信任。** 真实握手身份签发。每条新连接独立校验，保留已有用户及组织信任、撤销与 CA 约束。
- **G2 服务端授权。** 批准桌面安全模型。通过独立证据核对服务端生效策略、端口与 IPv4/IPv6 实际监听范围，批准登记及变更前撤销流程。
- **G3 会话安全。** 验证授权新鲜度、撤销、硬截止、目标及代次复核、真实进程所有权。真实流量准入依赖已验证的回执。
- **G4 托管和文件。** 验证使用受保护路径的托管启动、临时文件归属和权限、异常清理，以及本机 Relay 与远端已验证端点的绑定。
- **G5 AI。** G1–G4 通过后验证独立 AI 运载、隔离工具配置、CC Switch 实际路由和会话凭据撤销。

**PENDING** 表示待维护者实测。**BLOCKED** 表示缺少实现或审批，需先满足对应准入。[M5-Ready 审查](V0.3.0_M5_READINESS_REVIEW.md)
