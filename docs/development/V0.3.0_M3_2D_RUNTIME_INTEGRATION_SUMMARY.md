## 状态和资源所有权

`runtime.rs` 管理未准备、准备中、等待授权、等待资源就绪、离线可用、关闭中、已关闭和异常关闭。任务身份限制所有状态转换与资源交接，关闭结果缓存到原任务。旧任务和其他运行时的身份无法操作现有资源。

`runtime/local.rs` 从 `WindowsBridgePlan` 和主机身份检查建立租约作用域，使用 `PolicyLifecycle` 和 `PolicyStorage` 确认签名授权及持久历史，再持有 `FrozenResources` 和 `OwnedProcess`。启动受控子进程、校验配置和恢复线程前后重新检查授权。合成时钟到期即报告不可用，下一次轮询关闭资源。迟到的签名或历史异常不会延长有效期限。

进程和文件使用同一个关闭绝对截止。Job 等待上限为 5 秒，应用退出夹具传入 R4.6 的 200 毫秒预算。先停止进程和管道，确认 Job 结束后再清理具有已知身份的文件。关闭报告区分完整、部分、超期及失败。无法确认的对象保留待清理身份。同步 Win32 调用的中断和实际宿主退出调度仍为 PENDING。

其余实现变更集中在 `safety/mod.rs` 的作用域复用、`policy/lifecycle.rs` 的时效查询、`owned_process.rs` 与 `frozen_resources.rs` 的期限传递、`local_files.rs` 的按句柄删除以及 `policy_storage.rs` 的原子发布。测试变更涉及 `tests/mod.rs`、`tests/policy_lifecycle.rs`、`tests/policy_storage.rs`、`tests/process.rs`、`tests/runtime_integration.rs` 和 `tests/runtime_regression.rs`。三份阶段 Review 与开发索引随汇总交付。
