# M3.2-D2 Windows 本机生命周期联动

接续 D1 提交 `c90dadb22f6c18da7f22c30151392e4e57d07a62`。独立协调器从 `WindowsBridgePlan` 读取并复核当前上下文，复用现有主机身份、租约作用域和 `FrozenProfile` 生成逻辑。授权走 `PolicyLifecycle` 的签名、新鲜度、期限和 `PolicyStorage` 提交校验。然后创建并验证 `FrozenResources`，接收由隔离夹具启动的暂停 Job 子进程，逐次复验授权与文件后恢复线程。

离线可用状态只有一个所有者。时钟超过硬截止时查询立即返回不可用。主动轮询或授权刷新会观察授权异常并收尾。查询和存储涉及同步调用，开始前及返回后由原授权模型重新取样。来源异常、历史异常或超期均不能延长原授权。生产调度仍需独立定时器和可中断的外部调用。

关闭先撤销本机可用状态，再清理 Job 和管道，确认进程与 Job 已释放后清理冻结文件。报告区分完整、部分、超期与失败，并保留启动错误和待清理的文件身份。重复调用返回首次报告。意外释放所有者时也按进程、文件顺序回收。

| 期限 | 使用方式 |
| --- | --- |
| 授权租约上限 300 秒、状态上限 60 秒 | 由原策略和双时钟验证，最早期限决定可用性 |
| Job 等待上限 5 秒 | 取本次关闭绝对截止与原有上限的最早值，进程和 Job 共享剩余时间 |
| 文件清理 | 使用同一个绝对截止，在打开和删除前检查，耗尽时保留待清理记录 |
| R4.6 应用退出回调等待 200 毫秒 | 本机夹具传入同等预算进行协调验证，生产等待机制保持现有路径 |

定向联动覆盖正常、到期、撤销、重复关闭、来源不可用、损坏的 DPAPI 历史以及冻结目录创建冲突。原有 3 项冻结资源、2 项 Job、10 项策略夹具也独立复验。日志位于 `artifacts/v0.3.0/M3.2-D/`。单次同步 Win32 文件调用的中断上界、真实转发与真实应用退出仍为 PENDING。
