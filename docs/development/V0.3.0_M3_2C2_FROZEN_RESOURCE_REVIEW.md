# M3.2-C2 Windows 冻结文件生命周期

接续 C1 提交 `98b09ed9a2ff087effbc8b60a4b5a9495fdfb165`。`FrozenResources` 使用 C1 的私有目录、SID、DACL 和 NTFS 检查，复用现有 `FrozenProfile::check_files` 判断实际内容。

每次创建三个固定名称的文件。写入时记录原始文件 ID 和卷号，写入后刷盘。写句柄交接时用额外读句柄阻止路径替换，再将读取权移交给拒绝写入和删除共享的只读句柄。读取按原始长度多读一个字节，能拒绝尾部追加。目录、文件的所有者、权限、链接和 ID 在使用前复核。

关闭时先释放只读句柄，再按路径打开删除句柄，核对创建时的 ID 后按句柄删除。只处理本次记录的文件与空目录。文件被替换、归属不明或目录仍有外部内容时，清理结果保留资源名、已知文件 ID 和错误。创建目录成功后若未能验证身份，返回未知 ID 的待清理项。重复关闭成功后保持幂等。待清理项由调用方接收，真实应用异常退出后的持久化与重查仍待验收。
