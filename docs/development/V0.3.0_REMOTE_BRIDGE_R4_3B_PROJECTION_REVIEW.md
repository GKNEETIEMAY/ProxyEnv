- `mod.rs` 增加私有模块和内部导入，迁出五个定义。`projection.rs` 中三个跨模块调用的函数使用 `pub(super)`，两个报告脱敏辅助函数保持私有。
- 逐字节比较迁移前后的五个函数体，形参与返回类型一致。把移动和导入从差异中扣除后，根模块剩余内容逐字节一致，包括 `Summary`、`Report`、Serde `camelCase`、`skip` 与默认值，报告缓存及 `StoreGuard::drop` 的顺序。
- Node 三个相关脚本、Tauri 命令、能力切换、诊断和适配器均原样保留。报告仍只读缓存；UI 不增加 SSH 等待。源码与既有测试继续核对报告脱敏、缓存争用行为和 CLI/扩展独立性。
- 新增一项 Rust 测试 `bridge_projection_matches_pre_extraction_json`。用迁移前的 R4.3a 函数从合成状态采集完整的 `Report` 与纯 `Summary` 投影，迁移后逐项比较六组快照，覆盖无目标、断开、重连中、指纹失效、扩展异常与工具禁用。JSON 仅含合成数据，摘要中的目标使用保留测试域名，报告仍按原允许列表投影。[测试](../../src-tauri/src/features/remote_bridge/tests.rs) · [迁移前快照](../../src-tauri/src/features/remote_bridge/fixtures/projection_baseline.json)
