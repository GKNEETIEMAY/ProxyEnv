# 给应用配置代理：v0.2.2 实施范围

状态：已在 v0.2.2dev 实施，2026-10-23。按维护者确认的方案，将原“检查应用代理配置”收敛为手动填写代理信息与按需带变量启动。

## 用户任务

帮助用户将当前活动代理填入应用的网络设置；应用没有代理设置时，可以尝试带代理变量启动。请求到达本地代理后的分流由代理软件决定。

## 当前界面

1. 主页入口与上下文页标题统一为“给应用配置代理”。
2. 默认展示本机代理环境状态、一行完整地址和折叠的启动入口；服务器与端口放进“分开填写”折叠区，各字段可复制。无需先选择应用。
3. HTTP / SOCKS5 选项只显示当前端点支持的协议；Mixed 支持切换。IPv6 完整地址使用方括号。
4. 状态直接复用主页已有数据，分别展示已配置、未配置、尚未同步、待刷新或代理不可用；不推断应用行为。“？”说明环境变量继承的局限、地址来源、字段填写方式、认证信息需查看代理客户端，以及实际分流的归属。
5. “应用没有代理设置？”下按需展开应用列表，保留名称/路径搜索、刷新和浏览选择。
6. 选中后列表收起，保留名称、更换入口和启动按钮；点击“带代理变量启动”才调用既有启动接口。启动成功只确认新进程已创建，提示用户回到应用验证。
7. 延续本机环境与远程桥接的标题、间距、细分割线和按钮样式。环境状态复用共享状态标记；支持多种协议时使用分段切换，完整地址采用主页端点的强调色与等宽字体。窄窗口的状态说明单独成行。简体中文、英文、日文、韩文均有文案。

## 操作边界

- 页面打开不枚举应用、不诊断应用、不测试目标服务、不修改环境变量或应用配置。
- 应用列表仅在用户展开或刷新时读取；用户选择应用不触发启动。
- 复用既有应用授权、授权续期及后台代理 revision 校验。授权等待期间切换代理会阻止此次启动。
- 端点不可用或协议未知时，不提供可复制的填写信息，并禁用带变量启动。
- 带变量启动只对支持这些变量的应用有效；运行中应用可能复用旧进程。提示用户自行完全退出后再尝试，不提供结束进程或自动重启操作。
- 成功结果为“已启动应用”，不表示应用已经联网或实际经过远端代理节点。
- 该流程不读取分流规则，不切换直连/规则/全局，不提供无变量启动或自动修复。
- 移除旧诊断向导和手动配置弹窗的前端入口。诊断报告与后端既有接口不在本次修改范围内。
- 清理旧向导、结果页和配置弹窗的未使用样式与多语言文案；保留应用选择列表以及诊断报告仍在使用的内容。

## 验证

组件回归使用合成 IPC，覆盖主页环境状态变化、过期状态、默认折叠、选中后收起列表、打开无副作用、协议与 IPv6 地址复制、搜索/浏览、显式启动、授权过期恢复、切换代理竞态、失败恢复及不可用状态。四种语言在宽/窄窗口、明/暗主题下检查默认信息区和展开区。不会在测试中启动真实应用或写入真实代理配置。
