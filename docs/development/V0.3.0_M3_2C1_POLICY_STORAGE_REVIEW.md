# M3.2-C1 Windows 授权历史存储

基线为 `06221933dd11d82eedc5617f1bcc5d613b08f96e`，开工时本地、远端和 CI 的提交一致。六项 CI 均通过，Linux 扩展为 45 通过。[基线 CI](https://github.com/GKNEETIEMAY/ProxyEnv/actions/runs/45863021705)

`PolicyStorage` 实现现有 `PolicyHistory`。首次初始化必须独占创建新目录。读取已有目录时，锁或快照缺失会失败。只有已成功解密且结构完整的索引能返回某个作用域从未登记。索引包含签发公钥、审查 ID、修订和部署，记录中包含状态序号、摘要和撤销位。

目录、锁和数据采用当前用户 SID 的受保护 DACL。打开路径前固定父目录，拒绝重解析对象和非 NTFS 目录，核对文件类型、链接数、所有者和 DACL。状态快照使用当前用户 DPAPI，附加数据绑定用途、卷序号和目录文件 ID。跨进程事务以同一个锁文件的排他句柄串行化。比较和提交在同一临界区内，撤销状态对同一作用域保持生效。[DPAPI](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)

新快照经由独占创建的同目录临时文件写入并刷盘，再用文件句柄原子替换旧快照。发布失败会尝试按句柄删除本次临时文件。进程在发布前中断时，重开只读正式快照。实际掉电、恢复后目录元数据持久性和整份历史回滚仍待验证，授权仍依赖独立来源的最新签名状态。已有目录初始化失败时保留失败证据，恢复需单独确认归属。
