## Rust 路径与 Serde/IPC

`models` 为私有模块，根模块用显式 `pub use` 保留七个 `remote_bridge::类型名`。逐字节比较 Git 中的原定义和新文件，声明、派生特征、Serde 属性、默认值位置、枚举及字段顺序一致。根模块的其余差异为模块声明及重导出。[模型源码](../../src-tauri/src/features/remote_bridge/models.rs) · [根模块](../../src-tauri/src/features/remote_bridge/mod.rs)

- 目标和认证用例覆盖四组枚举的全部字符串值、`RemoteTarget` 字段顺序和显式 `null`，以及未知来源和越界端口拒绝。验证 `SshAuthState::default()` 的 `nonInteractive`、`unknown` 和两项 `false`，以及 `Summary` 的 `target`、`sshAuth` 嵌套输出。
- 请求用例覆盖 `targetId`、`proxyPort`、`ccPort`、`ccLocalPort`、`expectedRevision` 的大小写和顺序，省略可选端口时会回到显式 `null`。要求的修订字段、越界端口和未知字段仍按现有规则拒绝。
- 原路径上导入和构造 DTO 的 Rust 测试，以及原 Tauri 命令的编译，验证现有调用接口。目标列表与增改仍返回 `RemoteTarget`，预览和连接仍接收 `Request`、返回 `Summary`。序列化断言按现有前端接口书写。 [命令源文件](../../src-tauri/src/commands/remote_bridge.rs) · [前端 IPC 类型](../../src/features/remote-bridge/state.ts)
