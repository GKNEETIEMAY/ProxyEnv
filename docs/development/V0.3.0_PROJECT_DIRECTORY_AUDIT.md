## 路径契约

| 读取方 | 依赖及验收 |
| --- | --- |
| `remote_bridge/mod.rs` | `#[path]` 让 SSH 认证、凭据缓存和两种 Relay 保持根模块逻辑路径。根尾部测试可沿用 `remote_bridge::tests`，既有 `use super::*` 可见性相同。 |
| `target_os/linux.rs`、`linux_contract.rs` | `include_str!` 加载桥接根的三个 Shell 文件和一个生成的 CJS 文件，契约夹具读取同目录 `linux-wire.sha256`。验收比较全部 26 项原始载荷及无效参数路径。 |
| 扩展构建和打包 | `build-remote-extension.mjs` 固定 CJS 输出，`--check` 校验产物。Rust `build.rs` 基于 `CARGO_MANIFEST_DIR` 读取规则，生成到 `OUT_DIR`，Tauri 从 `resources/app-rules/*.json` 打包规则、从 `../dist` 打包前端。 |
| TypeScript、Vue 和资产 | 前端按现有相对路径导入，Vite 将 `public/` 文件作为公开路径。README 和文档引用保留原相对关系。 |
| Node 与 CI | `test:remote`、`test:docs`、`test:release`、`test:extensions` 由 `package.json` 及 CI 调用。品牌、发行、远程桥接测试已用新 SSH/Relay 路径，源码断言仍读取根模块的生产逻辑。 |
| 文档 | 开发索引位于开发目录内。公开文档索引遵守现有的正文与归档链接契约。 |
