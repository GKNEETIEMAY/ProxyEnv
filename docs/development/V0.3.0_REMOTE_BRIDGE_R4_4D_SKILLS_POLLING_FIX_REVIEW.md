## 基线问题与修复

同一夹具直接执行页面中的 Skills 函数、Vue watcher 及挂载和卸载回调。以合成 IPC、假时钟和延迟 Promise 在基线复现五个问题。断连后旧列表被写回，卸载后旧轮询重启，目标切换和同一目标重连时旧列表覆盖新列表，迟到的启停结果触发了新目标的刷新。原来的 2200 ms 轮询、繁忙跳过、请求失败重试和预览行为通过了基线对照。[测试](../../scripts/test-remote-skills-polling.mjs)

页面在 SSH 连接状态或已连接目标 ID 变化时立即递增 Skills 代次，清空旧列表并重新安排当前目标的单个计时器。卸载时递增代次并取消计时器。读取、轮询及启停回执只对原代次生效。目标切换的首次刷新仍由原汇总 watcher 触发，连接时的刷新仍走原调用路径。启用、停用 IPC 与失败提示沿用现有实现。此提交单独修复既有竞态，Skills 状态提取留待独立审查后开展。[页面](../../src/features/remote-bridge/components/RemoteBridgePage.vue)
