## 定向验证与基线差异

- `installation_snapshot_invalidation_and_generation_guards_are_independent_of_core_bridge` 继续拒绝目标 ID、SSH 指纹、连接代次或发现 ticket 任一不匹配的结果。新增断言验证同一指纹保留快照，指纹变化仅重置发现快照并把 ticket 从 9 推进到 10，无快照时再次失效不再推进。现有连接、会话指纹和代次、已配置状态、会话环境、明确关闭的工具及同步状态均保留。
- `automatic_setup_preserves_explicit_off_and_skips_already_configured_tools` 继续拒绝明确关闭或已配置的工具，并补齐 Claude 已配置时的拒绝断言。断开 transport 前先证明 Claude 已满足其余资格条件，断开后再核对其被拒绝。重复资格判断后，序列化 Summary 和关闭列表保持一致。
- `automatic_setup_requires_an_enabled_route_and_compatible_cli_or_plugin` 原样覆盖 Codex 和 Claude 的 CLI/插件状态组合，包括任一端为 `Checking`、至少一端为 `Installed`、CC 路由断开或端点缺失。总计补强两项现有用例，测试数量不变。
