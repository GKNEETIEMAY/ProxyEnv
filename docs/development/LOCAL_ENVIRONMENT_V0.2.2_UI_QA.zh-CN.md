# v0.2.2dev 可重复 UI 验证与 Windows 人工验收

当前稳定版 v0.2.1；本页只记录开发验证方法。模拟 UI 与原生系统验收分开计数。

## 仓库内可重复执行

Node 20.19 或仓库允许的更高版本、固定 pnpm 10.15.1；在仓库根目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
pnpm test:ui
```

`playwright` 固定为 1.64.1，浏览器 revision 随该版本锁定；CI 使用它安装的 Chromium，不使用机器自带 Edge。`test:ui` 先用 Vite 编译两份 fixture 到忽略目录下的 `site/`，再在进程内启动 Vite preview 127.0.0.1:1422，确认 fixture 可访问后按顺序运行两套 UI 测试，最后关闭服务。这样不依赖开发服务的依赖扫描和缓存。端口已占用时失败，不结束其他服务。每套测试在退出时关闭浏览器，失败保存截图；日志和模拟截图位于 `.impeccable/review/local-v0.2.2/`，CI 作为 `local-ui-fixtures` artifact 上传。

已自行启动 Vite 时，也可设置 `PROXYENV_LAYOUT_URL` 后运行 `pnpm test:local:ui` 或 `pnpm test:assistant:ui`。`PROXYENV_LAYOUT_BROWSER` 可用于开发者的指定浏览器；`PROXYENV_LAYOUT_PLAYWRIGHT` 仅在仓库包缺失时作为旧运行时回退。这些开发覆盖方式不用于固定版本 CI。

两套 fixture 的浏览器请求限于 127.0.0.1。IPC、应用列表和环境状态全部为合成数据，测试不会启动真实应用、探测真实外网目标或修改注册表/用户代理变量。

## 模拟覆盖

| 范围 | 自动化证据 |
|---|---|
| 本机概述/高级 | 四语言 × warm/blue/teal/neutral × 亮暗 × 560/880/1280 × 两视图，共 192 个布局组合；断言实际配色、内容宽度和按钮无裁剪 |

| 变量与手动配置 | 当前值与下次同步范围区分、至少一项、协议不适配、NO_PROXY 只读、长值、取消确认无写入事件、显式确认 |
| 连通性 | 未检测、检测中、操作失败、监听失败/协议未执行、0/1/2/3 个目标通过、缓存过期、详细错误和帮助信息；仅确认组件展示与事件 |
| 应用配置操作 | 初始不枚举；名称/路径搜索、浏览、独立复制；选择不启动，显式启动、授权续期和代理 revision 改变时拒绝旧操作 |
| 编排与并发 | `pnpm test:local` 的可控时钟、A→B→A、缓存晚到、慢刷新、同步/清除/恢复、设置保存失败等确定性测试 |

每一项仅以实际命令结果为准；截图不能证明注册表写入、外网连通或安装升级成功。
