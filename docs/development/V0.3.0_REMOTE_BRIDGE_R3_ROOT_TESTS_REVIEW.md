## Diff 摘要

- `mod.rs` 的尾部模块改为 `#[cfg(test)] mod tests;`，减少 733 行。替换点之前的源码逐字节与 R2 相同。根文件内独立的 `vscode_launch_tests` 仍按原位置和模块编译。
- `tests.rs` 包含原 23 个测试与夹具。提取时的缩进可无损回拼，随后只用 rustfmt 统一迁移后的缩进和换行。保留 Rust 逻辑路径、函数名、测试属性和原有 `super` 可见性。
- 新增 R0 审计、开发索引、本 Review 和后续拆分设计。设计含 Rust 调用与共享状态矩阵、页面拆分候选和脚本夹具提取方案。[R0 审计](V0.3.0_PROJECT_DIRECTORY_AUDIT.md) · [后续拆分设计](V0.3.0_REMOTE_BRIDGE_R4_SPLIT_DESIGN.md)

首轮 rustfmt 报告部分行在去掉一层缩进后应重新换行，格式差异保留于 `fmt-first.log`。RustSec 首次在线请求因公告库 TLS 握手中断，原日志保留于 `cargo-audit.log`，缓存补查单独记录。
