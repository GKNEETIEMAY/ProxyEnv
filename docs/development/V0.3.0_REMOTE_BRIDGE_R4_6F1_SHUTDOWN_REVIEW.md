## 资源归属和状态顺序

- `shutdown` 原子接管关停，重复调用直接返回。退出回调给唯一清理线程最多 200 ms 的等待窗口。
- 清理线程接管 Store 之前，现有资源仍由原 Store 持有。获得锁后递增连接代次，取出退役状态，并沿用 `StoreGuard::drop` 发布 Disconnected 的 Report 与 Tray。释放锁后按原顺序释放主 SSH、其他隧道和 Relay。
- 认证会话从会话表转移给同一清理线程，在会话表锁外释放。随后清理凭据并关闭日志。默认清理路径移除了交互取消对 Store 的反向取锁。正常断开和普通认证取消仍走原路径。
