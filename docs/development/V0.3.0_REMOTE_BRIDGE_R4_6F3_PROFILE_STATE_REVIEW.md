# RouteSpan v0.3.0dev R4.6-F3 Profile 任务归属

基线为 F2 提交 `0a56059b132b5b765d46523e690fec3c0da18f5b`。[R4.6b](V0.3.0_REMOTE_BRIDGE_R4_6B_GENERATION_REVIEW.md) 记录了旧任务回执清掉新任务忙位并覆盖 Codex 状态的 3/3 次复现。

## 状态与回执

Store 仍持有单一同步槽。每次认领把工具、连接代次与任务序号一起写入该槽。清槽、设置工具状态、回写现有缓存和消费成功回执前，相关路径均在同一 Store 锁下核对所有者。初始读取失败、防抖期间文件变化、预览失败、缺失哈希、应用失败、回读冲突和最终成功回执均受这一身份约束。

传输丢失和主动断开撤销槽位，新连接意图在递增代次时撤销槽位。正常恢复即使使用同一连接代次，后续认领仍会使用新序号。关闭 Codex 跟随或显式恢复工具配置只撤销相应工具的任务。

现有轮询次序、两段 500 ms 防抖、缓存匹配、预览/应用载荷以及回读验证保留。预览和应用分别仍使用原请求，已派发的远端操作副作用是独立的待验边界。
