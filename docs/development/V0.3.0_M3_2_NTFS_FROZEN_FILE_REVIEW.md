## NTFS 设计与验证

Windows 专用测试在本地 NTFS 的随机工作目录子路径构造合成配置与公钥文本。目录和文件在创建时应用受保护的 DACL，随后通过打开的句柄取回所有者与 DACL 并与预期比较。
生产代码仍使用原有的 `FrozenProfile` 渲染、主机信任和 Relay 鉴权。测试只为现有 Windows 依赖声明 ACL API 的开发功能。[NTFS 夹具](../../src-tauri/src/features/remote_bridge/target_os/windows/bridge/safety/tests/ntfs.rs)

| 用例 | 必须观察到的结果 |
| --- | --- |
| ACL | 私有目录和普通文件符合预期所有者及受保护 DACL。带 `Authenticated Users` 读取 ACE 的文件被拒绝。 |
| Reparse point、hardlink | 对真实 NTFS junction 使用不跟随链接的打开方式发现重解析属性。对拥有第二个硬链接名的文件按链接数拒绝。 |
| 文件 ID 与共享 | 读取 128 位文件 ID 和卷序号。写句柄存活时无法取得更严格的只读句柄。关闭写句柄后，保留禁止删除的读取锚，继续拒绝重命名。固定的目录句柄也拒绝目录改名。 |
| TOCTOU | 交接期间用第二个句柄修改字节，复核拒绝。持有最终只读句柄时写入和替换均失败。故意撤去保护后放入内容符合预期的新文件，复核通过不同文件 ID 拒绝。 |
| 清理 | 关闭句柄后逐项移除记录里的合成文件、链接和已知目录。清理按对象路径逐项执行，junction 使用只删除链接自身的目录删除语义。 |
| Windows OpenSSH 离线读取 | 三份文件持有只读共享句柄时，系统 `ssh -G -T -F` 读取真实配置并输出预期主机、端口和两条信任文件路径。独占 `ssh_config` 后读取失败。系统 `ssh-keygen -F` 实际读取合成 `known_hosts`，`ssh-keygen -l` 解析合成撤销公钥文件。 |

夹具的 ACL 负例验证 DACL 识别，其他 Windows 用户令牌的实测访问验收仍为 **PENDING**。文件交接测试覆盖受控目录，正式接线还须验证实际部署根的所有祖先及目录权限。
固定路径的离线读取沿用现有渲染器支持的路径范围。配置和公钥工具的读取证据仅覆盖解析阶段。真实 OpenSSH 握手与撤销执行、Linux SSH/SCP、持续撤销和真实文件生命周期验收仍为 **PENDING**。
`REVIEWED_TEST_HOSTS` 保持空表，本地夹具只使用无远端连接的参数。
