## 资源所有权和失败行为

- `local_files.rs` 固定 NTFS 父目录并核对边界内对象的 SID、DACL 和文件 ID。`policy_storage.rs` 通过新建的私有目录区分明确初始化与已有状态遗失。排他锁内完成比较与提交，同卷临时文件刷盘后按句柄发布。崩溃前遗留的阶段文件不会作为有效历史。DPAPI 保护本地数据，整份历史回滚仍需要独立权威来源处理。
- `frozen_resources.rs` 记录文件身份，持有受共享模式保护的只读句柄并核对原始配置字节。关闭时只删除确认属于当前实例的对象。身份不符、外部文件占用目录或清理失败会返回待清理记录。替换夹具首轮出现一次清理断言失败，后续定向及十轮重复通过，首次日志保留。
- `owned_process.rs` 独占本次创建的 Job、子进程及管道。子进程在加入 Job 前保持暂停，退出有界，关闭报告如实记录根进程、活动进程计数和终止请求。隔离 worker 验证父端断管、读端 EOF、正常和重复关闭。
- 只将 windows 0.61 的 `Win32_Security_Authorization` 提升为普通依赖功能，供 SID 和 DACL 检查使用。Pipes 仍为测试功能，依赖版本与锁文件一致。受审主机清单仍为空。
