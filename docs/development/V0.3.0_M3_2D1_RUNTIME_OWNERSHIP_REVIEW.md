`WindowsBridgePlan` 持有经校验的桥接上下文。现有 `PreparedForward` 和 `Verification` 持有冻结配置、旧前置验证及其独立证据。主机身份由 `VerifiedHostIdentity` 约束。新生命周期使用 `PolicyLifecycle` 和 `PolicyHistory`，Windows 历史适配器由 `PolicyStorage` 提供。冻结文件和 Job 分别由 `FrozenResources`、`OwnedProcess` 独占。D1 新增的 `Runtime` 管理一次离线任务的状态、资源交接和关闭结果。

状态依次为未准备、准备中、等待授权、等待资源就绪、离线可用、关闭中、已关闭或异常关闭。只有当前任务能推进状态、交接资源或关闭。确认授权后才可交接资源。关闭取走资源一次并保存结果，同任务的第二次关闭读取原结果。关闭后开启新任务会获得独立身份，旧任务和其他运行时的任务无法影响当前资源。
