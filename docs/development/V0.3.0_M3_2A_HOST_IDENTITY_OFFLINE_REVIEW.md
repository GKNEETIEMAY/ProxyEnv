## 本轮测试

现有独立校验已经覆盖本阶段设计，本轮只在测试模块补三个合成用例。

| 用例 | 新增断言 |
| --- | --- |
| `host_identity_is_bound_to_the_exact_effective_config_and_generation` | 相同绑定和代次返回固定合成指纹。账号端点相同的不同目标 ID 仍拒绝。端点未变的有效配置编辑或代次变化也会使旧身份失效 |
| `frozen_host_identity_rejects_unsupported_trust_entries` | 精确默认端口条目和明确的无关撤销公钥可生成固定材料。CA、哈希主机名、通配、多主机、错误端口格式及合并的 CA 条目均拒绝 |
| `frozen_host_identity_checks_blob_digest_and_revocation_bounds` | 拒绝使用 Base64 文本计算的摘要、超过 64 条的撤销材料和截断公钥。边界大小的有效材料按原契约保留 |

新增用例通过 `cargo test --manifest-path src-tauri/Cargo.toml --lib --locked host_identity` 独立执行。夹具使用固定字节、合成别名及纯本机值。原有 Windows 计划的负例继续覆盖主机密钥变化、代理变化、跳板、外部命令及未确认平台。[测试源码](../../src-tauri/src/features/remote_bridge/target_os/windows/bridge/safety/tests/mod.rs)
