# M3.2-C3 Windows 自有进程生命周期

接续 C2 提交 `c7f1de70eb9bee15729e0c168d3e9dbb51467573`。从已有 Windows Job 与管道夹具提取 `OwnedProcess`，沿用暂停创建、显式管道句柄清单、Job 归属核验及恢复主线程。夹具仅在隔离 worker 中使用启动函数。启动失败后，临时进程守卫处理自己持有的暂停子进程。诊断记录实际的终止请求及有界等待结果。

`OwnedProcess` 独占 Job、直接子进程、暂停线程和父端管道。关闭先释放管道，再终止所属 Job，等待根进程并读取 Job 内活动进程计数。结果分别记录进程已退出、Job 为空及终止错误。关闭保留首次观察的结果，重复调用返回同一结果。Job 句柄关闭时仍启用 kill-on-close。原有 worker 加入有界等待，若超期只终止本次启动的 worker。
