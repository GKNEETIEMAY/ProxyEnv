## 上一版稳定基线

旧品牌 ProxyEnv v0.1.4 是维护者指定的上一版稳定基线。
其 GitHub Release 仍为 Draft，最新公开 Release 为 v0.1.3。
指定稳定基线不代表草稿已经开放下载。

## 下一版：RouteSpan v0.2.0

`v0.2.0dev` 上已实现本机环境、远程桥接、CC Switch AI 路由延伸、工具准备、托管 Skills、
概述/高级和 RouteSpan 品牌，尚未发布。验收证据独立记录在[发行验收](RELEASE_QA_V0.2.zh-CN.md)。

## 发行门槛

- 解决前端依赖高危审计失败，重新运行最新代码完整 CI。
- 验证前版升级到 RouteSpan，保留安装身份/数据并验证卸载。
- 测试真实 Windows 10/11、125%/150% 原生 DPI 及桌面/托盘/安装图标缓存。
- 完成真实 SSH 密钥/Agent/密码/KBI、供应商、CLI/插件与共享主机矩阵。
- 验证重连、主动断开、崩溃恢复和仅恢复应用管理内容。
- 验证正式签名发行流程、更新失败/降级处理、校验值及外部产物来源证明。
- 复核发布后的 Markdown 渲染，记录剩余跨机器预览测试结果。

不承诺发布日期。本地自动化检查不能替代这些门槛。

## 未来研究

MCP 桥接、更多适配器和平台扩展需要独立设计。MCP 需要按能力限定授权、生命周期与回滚分析；
普通转发隧道和当前 Skills 同步都不等于已实现 MCP。
这些是研究方向，不是已发布功能或承诺。
