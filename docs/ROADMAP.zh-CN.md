# RouteSpan 路线图

[English](ROADMAP.md) · 简体中文

## 上一版稳定基线

旧品牌 ProxyEnv v0.1.4 是维护者指定的上一版稳定基线。
其 GitHub Release 已于 2026-10-13 公开发布，v0.1.3 与 v0.1.4 均为历史公开发行。
RouteSpan v0.2.0 是 v0.2.1 的前版。

## 已发布：RouteSpan v0.2.0

2026-10-13 已发布：本机环境、远程桥接、CC Switch AI 路由延伸、工具准备、
托管 Skills、概述/高级和 RouteSpan 品牌。发行门槛已关闭，包括正式自动更新冒烟。
[发行验收](RELEASE_QA_V0.2.zh-CN.md)区分当前发布状态与历史检查点，最终详细验收记录私下保存。

## 发布后的仓库依赖与安全维护

quinn-proto 0.11.18 已解决 RustSec lockfile 警告；受影响的 QUIC 功能未在
RouteSpan 的 Windows 依赖图中启用。后续发行构建必须在打包前通过固定版本的 Rust 依赖审计。
这些变更只影响后续源码/构建：已发布的 v0.2.0 资产未改变，tag 未移动，
没有替换已发布 binary，也不声称它已被修复。

## 已发布：RouteSpan v0.2.1

2026-10-20 从 `v0.2.1dev` 分支的 `85be2e1` 发布，包含更新可靠性与安装保护、四主题、安全托盘操作、显式开启的桌面提醒及
像素动作定向打磨。保留本机代理、CC Switch、CLI/插件及托管 Skills 的现有边界。
同时改进 Codex/Claude 配置状态、路由提示与紧凑日志显示。见
[公开发行](https://github.com/GKNEETIEMAY/ProxyEnv/releases/tag/v0.2.1)及
[四语发行说明](../.github/release-notes/v0.2.1.md)。

自动检查不替代真实 Windows 10/11、DPI、安装/升级、后台通知和远端服务器验收。
用户指定的淡色控件白字有已记录的对比度例外，详细设备记录仍私下保存。
维护者已确认升级和远端功能验收；CI、签名打包与独立产物验证均通过。
后续 tag/签名 Draft 与公开 Publish 仍分别需要授权。

## 后续发行继续保留的门槛

`v0.2.2dev` 正在实现本机概述/高级工作区、显式连通性检测和过期回包保护；
当前稳定版仍为 v0.2.1。见[开发方案](development/LOCAL_ENVIRONMENT_V0.2.2.zh-CN.md)
及[实施证据与待验收项](development/LOCAL_ENVIRONMENT_V0.2.2_QA.md)。开发记录不替代以下发行门槛。

- 保持前端高危审计门槛，发行预检变更重新运行完整 CI。
- 验证前版升级到 RouteSpan，保留安装身份/数据并验证卸载。
- 测试真实 Windows 10/11、125%/150% 原生 DPI 及桌面/托盘/安装图标缓存。
- 完成真实 SSH 密钥/Agent/密码/KBI、供应商、CLI/插件与共享主机矩阵。
- 验证重连、主动断开、崩溃恢复和仅恢复应用管理内容。
- 验证正式签名发行流程、更新失败/降级处理、校验值及外部产物来源证明。
- 复核发布后的 Markdown 渲染，记录限定范围的跨机器测试结果。

不承诺后续版本的发布日期。本地自动化检查不能替代手动验收门槛。

## 后续维护重点

- 桥接鉴权优化：改善 SSH 认证/恢复，以及 AI 会话鉴权的生命周期、提示和兼容性。
  保留主机指纹验证、令牌撤销和已公开的共享主机限制，不重新引入普通网络代理的账号密码认证。
- 修复小 bug 并打磨已有功能，优先处理连接/重连、工具配置和界面状态中可复现的问题。
  补充针对性回归测试，避免夹带无关协议改动或配置迁移。

以上是后续维护方向，不承诺发布日期，也不表示这些优化已经实现。

## 未来研究

MCP 桥接、更多适配器和平台扩展需要独立设计。MCP 需要按能力限定授权、生命周期与回滚分析；
普通转发隧道和当前 Skills 同步都不等于已实现 MCP。
这些是研究方向，不是已发布功能或承诺。
