## 上一版稳定基线

旧品牌 ProxyEnv v0.1.4 是维护者指定的上一版稳定基线。
其 GitHub Release 仍为 Draft，v0.1.3 是上一公开发行。
指定稳定基线不代表草稿已经开放下载。

## 已发布：RouteSpan v0.2.0

2026-10-13 已作为最新稳定版发布：本机环境、远程桥接、CC Switch AI 路由延伸、工具准备、
托管 Skills、概述/高级和 RouteSpan 品牌。发行门槛已关闭，包括正式自动更新冒烟。
[发行验收](RELEASE_QA_V0.2.zh-CN.md)区分当前发布状态与历史检查点，最终详细验收记录私下保存。

## 后续发行继续保留的门槛

- 保持前端高危审计门槛，发行预检变更重新运行完整 CI。
- 验证前版升级到 RouteSpan，保留安装身份/数据并验证卸载。
- 测试真实 Windows 10/11、125%/150% 原生 DPI 及桌面/托盘/安装图标缓存。
- 完成真实 SSH 密钥/Agent/密码/KBI、供应商、CLI/插件与共享主机矩阵。
- 验证重连、主动断开、崩溃恢复和仅恢复应用管理内容。
- 验证正式签名发行流程、更新失败/降级处理、校验值及外部产物来源证明。
- 复核发布后的 Markdown 渲染，记录限定范围的跨机器测试结果。

不承诺后续版本的发布日期。本地自动化检查不能替代手动验收门槛。

## 后续维护重点

- 桥接鉴权优化：改善 SSH 认证/恢复，以及 AI 会话鉴权的生命周期、提示和兼容性。
  保留主机指纹验证、令牌撤销和已公开的共享主机限制，不重新引入普通网络代理的账号密码认证。
- 修复小 bug 并打磨已有功能，优先处理连接/重连、工具配置和界面状态中可复现的问题。
  补充针对性回归测试，避免夹带无关协议改动或配置迁移。

以上是后续维护方向，不承诺发布日期，也不表示这些优化已经实现。

## 未来研究

MCP 桥接、更多适配器和平台扩展需要独立设计。MCP 需要按能力限定授权、生命周期与回滚分析；
普通转发隧道和当前 Skills 同步都不等于已实现 MCP。
这些是研究方向，不是已发布功能或承诺。
