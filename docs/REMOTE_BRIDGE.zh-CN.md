# RouteSpan 远程桥接

[English](REMOTE_BRIDGE.md) · 简体中文

这是 RouteSpan v0.2.0 远程桥接的唯一当前用户指南的中文版。它将选定的本机网络/AI 能力延伸到
非 root Linux SSH 账户，不是 VPN 或代理内核。RouteSpan v0.2.0 已公开发布。
安装要求与首次使用见[快速开始](GETTING_STARTED.zh-CN.md)。

## 连接来源

目标来自当前用户的 OpenSSH 配置、VS Code 明确指定的 SSH 配置、受支持的 MobaXterm 书签
以及手动保存的连接。来源标签用于区分它们。不支持的导入行为保持不可用；
发现连接名称不代表服务器允许反向转发。

添加/修改共用校验表单：显示名称（1–32 个字符）、主机或 `user@host`、端口（默认 22）、
用户名和认证方式。身份文件选择器只保存路径并检查有大小限制的密钥格式头部，
不上传或持久保存私钥正文；实际密钥解码和认证由 OpenSSH 完成。

修改导入连接会建立 RouteSpan 保存的副本并隐藏原条目。移除导入连接只是隐藏；
移除手动连接才删除应用保存的记录。两者均不重写 SSH 配置或 Moba 书签。
移除当前选择后会选择合适的剩余连接，或进入不能连接的空状态；刷新保留有效选择。

## 建立连接

在左侧选择目标，右侧选择能力，然后建立连接。没有额外确认页；转发前后端仍会重新验证
目标、本机端点与远端端口可用性。

密钥/Agent 登录使用原生 OpenSSH。交互登录显示真实密码/KBI 提示，回答只属于当前提示。
首次主机指纹需核实后明确确认；已有主机密钥不匹配不会绕过。取消会结束应用管理的认证尝试。

已连接表示 SSH 进程、所选中转和远端 Loopback 监听通过验证。可选准备随后独立进行。
SSH 成功不保证服务器直连网络、代理出口或模型响应成功。

## 桥接本机网络

此能力复用本机环境的活动代理选择，不另建一套检测，也不会悄悄更换上游。
所选协议和端点绑定本次会话。远端与本机端口不必相同：分配参考受支持的 VS Code 用户代理提示、
本机端口和占用情况。使用已连接概述中的实际端口，不要硬编码。

就绪后自动执行一次出口探测，不等待工具准备完成；必要时通过诊断重试。
监听验证通过不等于外网可用。普通代理刻意不设用户名/密码认证；Loopback 无法隔离共享主机上的 UID。
不能接受该风险时，请关闭此能力。

## CC Switch AI 路由

CC Switch 管理供应商、模型路由和上游凭据；RouteSpan 负责延伸。
使用前在 **CC Switch → 设置 → 路由 → 本地路由 → 路由总开关 → 开启 Claude/Codex 路由**中启用对应路由。
本机服务与地址从应用启动时开始检测，并持续刷新。确认服务身份不等于读取各工具的开关状态，
也不代表上游认证已成功。

AI 与网络开关独立，但均依赖 SSH。仅 AI 模式不需要普通代理环境导出；
需要 AI 和一般下载/网页访问时可同时开启。

请求通过后端管理的 `X-ProxyEnv-Session` 鉴权，不复制供应商密钥。中转保留请求/响应内容、工具调用与 SSE，
不会解释文本中的 DSML/工具标记，也不会转换不兼容的上游协议。已配置路由不等于真实模型请求已验证。

## Codex / Claude 工具状态

| 状态 | 含义 | 不代表 |
| --- | --- | --- |
| 已安装（Installed） | 发现兼容 CLI 或远程插件的安装证据 | 配置正确或供应商可访问 |
| 已配置（Configured） | 托管配置字段已写入并读回 | 模型成功响应 |
| 已验证（Verified） | 主动验证在对应范围内成功 | 所有入口/供应商均可用 |

CLI/插件版本独立。支持 Codex `0.x`，最低 `0.134`；支持 Claude `2.x`，会话 Header 访问要求 `2.1.227` 或更高。
兼容插件没有 CLI 也能配置。内置真实模型探测目前只支持已安装的 Claude CLI，
仅 Claude 插件或 Codex 不支持该探测；Codex 应通过实际 CLI/插件对话验证。

AI 路由开启、检测完成后，兼容工具自动准备，除非本次会话已明确关闭。
CLI/插件共用工具的标准远端配置，不重复执行事务。开启执行验证、备份、原子写入和读回；
关闭恢复管理字段并保留无关内容。管理归属证据冲突时停止事务。

已启用配置随本机变化同步：每两秒轻量元数据检查，变化后 debounce，再完整解析/hash 并协调配置。
桥接停止时不轮询配置。运行中的客户端可能需要重启/重载才能使用新模型或供应商。
不复制真实供应商密钥、`auth.json`、首次使用引导或项目信任。

安装指引提供你自行执行的命令，不自动安装。命令找不到可能是 `~/.local/bin` 或 npm 前缀不在 PATH 中，
参考[快速开始](GETTING_STARTED.zh-CN.md)，不要盲目重装。

## Skills

来源仅限本机 Codex/Claude Skills 目录下、指向 CC Switch 托管目录的同名链接。
排除原生 Skills、Codex `.system`、无关链接及嵌套链接。同名条目合并显示，每个智能体独立控制；
检测到的托管链接默认启用，除非主动关闭。

展开概述中的管理器，可搜索、同步或取消。连接期间动态检测变化；CC Switch 移除链接后，
相应应用管理的远端副本也会移除。取消绝不删除本机 Skill 或无关远端文件。
其它程序拥有的同名目录属于冲突，不能覆盖。

## 启动入口

- **打开终端**：打开已确认目标并加载会话环境。
- **在 VS Code 中打开**：使用检测到的安装（含受支持的便携版/快捷方式路径）和匹配的 SSH 配置。
  临时网络设置针对远端 Server，不修改本机 Windows User Settings。
- **MobaXterm**：使用受支持的目标/书签启动方式，外部 Shell 可能需要复制的会话配置命令。
- **复制终端配置**：复制不含 Token 的命令，在已认证的远端 Shell 中执行；复制成功不代表已经执行。

新服务器先允许 Remote - SSH 初始化 Server，再从 RouteSpan 重试。
环境变化后重载已有 Remote 窗口、重新创建终端。端口面板不能证明反向转发是否成功。

## 概述与高级

概述提供能力开关、工具准备、默认折叠的 Skills 和启动按钮。
高级提供环境事实、链路验证、SSH 传输说明、安全边界、事件与手动工具。
两页读取后端共享观察结果；切换页面不重置有效结果。

服务器直连网络独立检查，探测时绕过代理变量。首次连接不发起付费模型请求；
主动模型验证可能消耗 Token，失败原因在最近事件中显示。
VS Code 用户代理提示不代表进程/配置档/工作区中的最终生效设置。

## 重连与断开

传输丢失后，在有限次数/时限内使用原目标、端口和会话恢复。普通重试与成功保持静默；
认证、主机密钥或配置变化可能需要你处理。恢复不重放应用请求，也不替换代理。

手动断开先使恢复任务失效、撤销中转，再尝试恢复应用管理的 VS Code 设置并清理会话。
会话 SSH 凭据清除；启用的工具配置保留，但旧 Token 不能访问已断开的路由。
关闭工具才恢复其管理字段。崩溃/强制退出可能留下事务记录；恢复证据冲突时停止清理，不猜测。

## 常见问题

| 问题 | 安全的下一步 |
| --- | --- |
| SSH 失败 / 主机含 `:22` | 分开填写主机/端口；终端使用 `ssh -p 22 user@host` |
| 新主机或主机密钥变化 | 核实信任，不关闭主机密钥检查 |
| 已连接但无法访问外网 | 检查本机代理、网络开关、出口结果及当前会话环境 |
| AI 401 | 区分会话拒绝与上游认证失败，检查 CC Switch，不分享密钥 |
| VS Code 407 / 旧代理 | 重载 Remote 窗口，检查配置及配置档/工作区覆盖项 |
| VS Code 首次启动不可用 | 确认本机 VS Code/Remote - SSH，初始化 Server 后重试安全配置 |
| 配置冲突 / 路径不安全 | 检查归属、恢复证据与权限，不删除未知备份或对共享路径大范围 chmod |
| 模型列表不变 | 等待同步后重启/重载，客户端可能缓存旧设置 |
| 已安装但未配置 | 检查兼容性、AI 开关、工具是否主动关闭及准备错误 |

反馈使用脱敏报告/事件，参考[安全策略](../SECURITY.zh-CN.md)。
不要发送私钥、密码、完整设置或会话 Header。root 和同账户恶意进程不在隔离保证范围内。
