# v0.2 Remote Bridge scope

**Status:** development on `v0.2.0dev`, not a published release. Stable remains v0.1.4. See [acceptance](ACCEPTANCE_V0.2.md) for evidence rather than interpreting implementation as verification.

## In scope

| Capability | Current state |
| --- | --- |
| Codex/Claude shared profile and pure Codex traffic relay | Implemented; Codex VS Code Remote conversation, file edit and tool use accepted on one target; remaining scenarios pending |
| Structured OpenSSH/VS Code/Moba target discovery, SSH auth, explicit reverse forwards | Implemented; full compatibility acceptance pending |
| M8 authenticated session relay and token revocation | Implemented with automated tests; real different-UID shared-host acceptance remains a release gate |
| Import plus manual SSH connection manager, compatible Moba launch | Implemented; real-device release acceptance pending |
| ProxyEnv-owned session shell environment | Implemented with ownership checks; real-device lifecycle acceptance pending |
| Effective local Skills projection with staging, ownership and restore | Pending |
| Simple default / Advanced progressive disclosure | Pending |
| CI security fixes, documentation and live acceptance | Pending |

The M10-v0.2 focus is productization, not adding more AI clients. Backend-generated configuration and explicit user action remain requirements for any protected operation.

## Out of scope

MCP projection/bridge, automatic installation of MCP/Node/Python runtimes, Gemini/OpenCode/OpenClaw adapters, macOS Remote Bridge, TUN control and a second AI Gateway. Do not restore per-request model rewriting, DSML interpretation, Capability Overlay or an extension-only Codex profile.
