## 展示契约

本次 README 扩展采用 Read（阅读）模式，用插图解释工作流/能力路径，不改产品身份。

- 工作流人物/电脑与网络架构使用一致线稿。新增插图保持纯白底、圆头线条人物、
  炭灰描边与少量低饱和橙/蓝/青点缀。
- 语义 HTML 图片居中，阅读宽度上限 880px（`width="880"`，由渲染器响应式约束）。
  每图链接完整 PNG，窄屏可点击放大阅读小标签。
- 共用短英文图内标签，周边正文、alt 和 Windows/MIT 徽标 alt 本地化。
  两份 README 保持相同平台/许可证徽标。
- 保留概念边界：工作流勾选只示意准备，架构箭头只示意能力流向；
  网络/AI 反向转发与选定 Skills 文件同步分开显示。

2026-10-12 使用内置图像生成工具制作，遵循线稿、白底及克制橙/蓝/青色参考。
只作文档资产，不替换用户提供的 RouteSpan 品牌 PNG 或原生图标。

新增两图在视觉复核后参考 `routespan-workflow.png` 编辑，去除大面积色块和卡通衣物，
恢复原白底线稿。周边本地化正文补充行为边界。
