# README illustrations

English · [简体中文](README.zh-CN.md)

Four conceptual PNGs explain RouteSpan; they are not application screenshots,
network/model test results or real-device acceptance evidence. Both READMEs share
the artwork with localized descriptions and alt text.

- [Workflow](routespan-workflow.png): scattered setup versus a selected remote
  workspace. Checks illustrate intended preparation, not guaranteed connectivity.
- [Architecture](routespan-architecture.png): local capabilities extended to a
  remote Linux account. Network/AI reverse forwarding and selected Skills file
  synchronization are separate; arrows show capability flow, not packet direction.
- [Application launch](routespan-app-launch.png): proxy/direct choice for a new
  process. Running apps stay unchanged; launch does not prove network access.
- [Tool readiness](routespan-tool-readiness.png): independent CLI/plugin discovery,
  route configuration and verified requests. Setup does not prove a real request.

## Presentation rules

Use pure white backgrounds, round-headed line-art people, charcoal strokes and
small muted orange/blue/teal accents. Center images at a responsive 880px reading
width and link full-size PNGs. Keep short English in-image labels, localized
adjoining prose and alt text, and the Windows/MIT badges. Do not replace the
user-supplied brand PNG or native icons.
