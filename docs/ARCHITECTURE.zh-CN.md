## 产品边界

RouteSpan 观察本机代理层，管理选定的当前用户环境变量，并经 SSH 延伸明确启用的本机能力。
CC Switch 管理 AI 供应商/路由；RouteSpan 提供传输和选定客户端配置/Skills 映射，
不管理供应商或转换协议。普通网络与 AI 是独立通道，共用一个应用管理的 SSH 传输。

## 前端架构

依赖方向为 `App.vue → app → features → shared`。外壳管理本机环境/远程桥接导航、
应用助手/设置的上下文返回与全局诊断报告。主页面切换可见性但保持挂载，不重建连接状态。
概述与高级共用已连接页头和后端摘要，不各建状态存储。

会话级 ActiveProxyContext 由检测、环境操作、助手与远程配置复用。
外壳每五秒收集本机观察结果，不能悄悄替换用户选定的端点。
CC Switch 服务从应用初始化开始检测，保持独立观察状态。

共享状态/检查/帮助组件和右上角 NotificationCenter 统一操作反馈。
通知只在会话中保留并去重；字段校验和长期工作流结果留在对应控件旁。
诊断快照由后端保存并进行 generation/ticket 校验，切换页面不重置已完成结果，
也不接收旧目标的迟到结果。

## 本机环境

系统代理与 TUN 只读观察。注册表只写入选定的 `HKCU\\Environment` 字段：
读取/快照 → 应用 → 广播/读回，失败时回滚。恢复发现冲突会停止，不替换后续用户修改。
不会重写运行中进程的环境。

应用助手用短期后端身份授权规范化可执行文件，再以明确的代理/直连变量启动新进程。
例外的手动引导重启需要额外确认和最新进程身份检查。
内置配置规则是受限数据，不是可执行插件，也不保证支持任意应用配置。

## 远程桥接

### 目标检测与 SSH 认证

不透明目标 ID 绑定来源、文件身份和别名/书签。受限来源为当前用户 OpenSSH 配置、
VS Code 明确指定的 SSH 配置、受支持的 Moba 书签和手动连接，不导入密码/书签凭据段。
修改导入数据会建立应用拥有的副本；移除只隐藏来源，不粗暴重写外部配置。

原生 OpenSSH 解析别名、密钥、Agent 和受支持的跳板行为。
非交互路径拒绝未知主机；交互首次信任需要明确确认；密钥变化始终失败。
禁用 Agent/X11 转发和本地命令。PTY 解析器处理分段控制序列与提示 ID，不猜测密码问题；
回答不进入命令参数。

符合条件的普通服务器密码可作为绑定目标的 DPAPI 密文暂存于本次桥接内存。
密钥口令、OTP 和未知回答不缓存；切换目标、拒绝、断开和退出会清除会话凭据。

### 核心就绪与反向转发

认证 → 核心桥接 → 连接后准备是不同阶段。
核心已连接要求应用拥有的 SSH 进程、中转存活，反向转发成功，并由远端 `ss` 确认 IPv4 Loopback 监听。
环境、VS Code、工具和 Skills 的可选准备独立进行，不阻塞该快照。

SSH 指向本机中转的实际端口，而不是直接指向检测到的代理；中转再连接后端审查选定的固定上游。
普通网络远端端口可参考受支持的本机 VS Code 用户代理提示或所选代理端口；AI 优先 15721。
占用时使用有限、确定的备选端口。两个通道独立分配并再次检查竞争；
提示不代表运行中扩展的最终代理设置。

能力关闭会阻断其中转，但保留已分配端口上下文。AI 关闭同时进行托管工具恢复/暂停；
重新启用复用安全事务。恢复保留目标、端口和现有会话，使用有边界的退避，
不轮换凭据、不自动换目标、不重放应用请求。断开在撤销和清理前使恢复 generation 失效。

### 普通网络代理

无凭据 HTTP/Mixed/SOCKS 转发保持双向与半关闭行为。
没有代理用户名/密码流程。固定上游转发不是任意本机目标网关；
AI 专用 Header 和代理授权不会作为普通网络凭据转发。

尚未检测且存活的网络通道会安排一次自动出口测试，结果绑定 generation/ticket，
不控制核心就绪，也不能证明所有网站可访问。手动重测需明确执行。
这是当前行为，不能沿用旧文档“所有外网检查都需主动执行”的说法。

### AI 路由

AI 请求使用 CSPRNG 生成的会话 Token，通过 `X-ProxyEnv-Session`（旧品牌兼容标识）鉴权。
后端执行常量时间校验，拒绝缺失、无效、过期和跨会话凭据，转发到固定 CC Switch 上游前移除 Header。
Token 不暴露给 WebView、报告、复制的环境导出或命令行。

中转保留受支持端点的流量、状态、Header、正文和 SSE，不解析模型或转换文本工具语法。
root 和同 UID 恶意进程仍处于信任/特权边界之外；普通 Loopback 没有按 UID 隔离保证。

### 工具适配与配置同步

Rust/TypeScript 对应适配器身份定义 Codex/Claude 检测、兼容性、配置和验证。
CLI/插件观察结果独立。兼容远程插件允许在没有 CLI 时配置共享配置；依赖 CLI 的探测仍不可用。
检测完成且 AI 路由开启时，自动准备未被主动关闭的兼容工具。

Codex 使用标准远端用户配置及应用管理的供应商/目录；Claude 使用 CLI/插件共享的标准用户设置。
事务读取最新状态、备份、原子合并允许字段并读回，保留无关字段；
格式错误、外来归属或恢复证据冲突时停止。Python JSON 工具支持 2.7/3，不猜测自定义配置根目录。

本机模型/配置映射排除供应商密钥、真实上游 URL、`auth.json`、MCP、首次使用引导和项目信任。
Codex 模型目录字节保持不透明。连接且启用期间每两秒检查 mtime/大小，变化后 debounce、
完整解析/hash，再协调管理字段；停止桥接不轮询。运行中的客户端可能需要重启/重载。

配置成功不是请求验证。当前付费模型探测只支持已安装且路由启用的 Claude CLI。
Codex 保持纯转发，无内置真实模型探测，需用实际客户端验证。
付费验证需主动执行，原因记录在类型化最近事件中。

### Skills

检测仅接受 Codex/Claude 顶层链接：其规范化同名目标必须是 CC Switch Skills 根目录的直接子项。
排除原生 Skills、Codex `.system`、无关链接和嵌套 reparse point。
同名条目在界面合并，各智能体映射独立。

连接期间元数据轮询检测链接/内容变化，再进行防抖 hash。
暂存采用受限普通文件传输、清单和 SHA-256；远端所有者/权限/链接检查与原子激活保护目标。
不覆盖外来同名内容。移除只影响应用拥有且未被改动的副本，不影响本机或无关远端文件。

### 会话环境与 VS Code

应用拥有的 `~/.proxyenv/sessions/<id>/env.sh` 不含 Token，导出大小写代理变量并合并 Loopback 绕过规则。
默认不修改 Shell 启动文件；RouteSpan 终端自动加载，外部 Shell 执行复制的命令。

VS Code 只修改检测到的远端 Server Machine JSONC：禁用继承的本机代理设置、
临时移除冲突的 `http.proxy`/`http.proxyAuthorization`、合并 `http.noProxy`，
准备 `terminal.integrated.env.linux`。本机 Windows User Settings 不变。
已有窗口/终端需要重载/重建，不补丁修改扩展包。

运行时和上级路径检查所有者/权限/链接。经验证的用户私有主组只有狭窄例外，
共享可写上级目录仍拒绝。缺少 Server/运行时可能需首次初始化；不安全/冲突状态阻止自动修改。
设置提示不代表真实插件请求成功。

断开先撤销中转，再尝试恢复 VS Code 和清理会话；启用的工具配置独立保留。
关闭工具恢复管理字段。异常结束可能留下恢复记录，后续清理仍检查冲突。

## 诊断与脱敏

报告在 IPC 前将不探测的快照投影为允许的枚举、计数、安全版本和标准客户端名称，
排除地址、用户名、路径、PID、原始错误、配置值和密钥。切换语言只格式化同一快照；
生成报告不发起新请求、不自动保存或上传。

远程类型化事件可写入有界滚动 JSONL 日志（3 个文件，每个 2 MiB）。
共享 Rust 脱敏只是纵深防御，不允许序列化原始摘要或请求。
清除日志只处理应用管理的日志。诊断报告 TXT 与运行时 JSONL 用途不同。

## 持久兼容标识

展示品牌为境枢 RouteSpan。旧品牌的 package/crate、`proxyenv_lib`、`proxyenv.exe`、应用 identifier、
`%LOCALAPPDATA%\\ProxyEnv`、`~/.proxyenv`、会话 Header、存储键、仓库和更新来源不变。
迁移前先阅读[内部契约](INTERNAL_CONTRACTS.zh-CN.md)。

## 更新与桌面生命周期

单实例注册先于托盘初始化；二次启动聚焦已有窗口，不建立第二个桥接。
托盘/关闭行为遵循已保存偏好。

官方 Tauri Updater 使用固定 HTTPS 来源、嵌入公钥、默认防降级和主动检查/安装操作。
已注册 NSIS 支持替换；MSI/便携版手动更新。不采用 Authenticode。
生成 Draft 不等于发布或验收，正式产物/签名要求见[发行安全](release-security.zh-CN.md)。

## 信任边界与验证

前端字符串、检测路径和现有远端文件均不可信。Rust 重新校验修改；本机/远端文件采用有界读取、
所有者/类型/链接检查，并在支持处原子写入。
生产 CSP 仅允许内置资源、IPC 和明确触发的 GitHub 更新检查，不加载任意远程脚本。

测试命令见[贡献指南](../CONTRIBUTING.zh-CN.md)，实际结果见[验收台账](RELEASE_QA_V0.2.zh-CN.md)。
Linux 测试、模拟浏览器和本地编译不能证明真实 Windows 升级、原生 DPI、SSH 或供应商行为。
